Privacy

This website collects as little as it can. It has no accounts, no forms and no advertising.

Last updated October 22, 2026.

This website

  • The site is hosted by Cloudflare. Like any web host, Cloudflare handles the basic information your browser sends to load a page, such as your IP address.
  • The site counts visits with Cloudflare Web Analytics. That tool does not use cookies. It does not track you across other websites.
  • The site loads its fonts from Google Fonts, so Google receives a standard request from your browser when a page opens.
  • The site sets no cookies of its own.

The Cobblecrest Archive

  • When you ask the Archivist a question, the question is sent to Anthropic, an AI company, so that its model can write the answer.
  • The Archive keeps a record of questions and answers. Andy uses that record to see what the guides are missing and to improve them.
  • To limit how many questions each visitor can ask per day, the Archive uses a coded tag made from your IP address. The same tag lets it count how many people use it each day. The tag changes every day, and the Archive does not store the address itself.
  • If you pass a question to the game master, the Archive keeps the name and note you type, and it sends Andy a Discord message with your question.
  • Please don't type personal details into the Archive. When you pass a question to the game master, a first name or nickname is enough.
  • Players under 13 should ask a parent before passing a question to the game master.

Other websites

Links on this site lead to other services, including State of Comics, Square for payments, Google Docs and Google Drive for the guides, and YouTube. Those services have their own privacy policies.

Children

The site does not knowingly collect personal information from children. Nothing published here names or describes homeschool students or their organization.
